# 🧠 Customer Segmentation using Hierarchical Clustering

## 📌 Project Overview
This project applies **Hierarchical Clustering** to segment customers based on their purchasing behavior using two key features:
- Annual Income
- Spending Score

The goal is to discover natural customer groups that can help in marketing strategy and business decision-making.

---

## 📊 Dataset Description
The dataset contains information about mall customers:

- Customer ID
- Gender
- Age
- Annual Income
- Spending Score (1-100)

---

## 🎯 Objective
The main objective is:
- Identify hidden patterns in customer behavior
- Group similar customers together without labeled data (Unsupervised Learning)

---

## 🧠 Methodology

The project follows a complete machine learning workflow:

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Selection
4. Feature Scaling
5. Hierarchical Clustering
6. Dendrogram Analysis
7. Cluster Visualization
8. Insights Extraction

---

## 🔥 Algorithm Used

### Hierarchical Clustering
A clustering technique that builds a tree-like structure (dendrogram) to group similar data points step by step.

---

## 📈 Key Insights

- Customers were segmented into 3 distinct groups
- Income and spending behavior show strong relationships
- Hierarchical clustering provided clear and interpretable segmentation
- No need to predefine number of clusters manually

---

## 📊 Visualization Results

- Dendrogram used to determine optimal clusters
- Scatter plot used to visualize final clusters

---

## 🚀 Conclusion
Hierarchical Clustering is an effective unsupervised learning technique for customer segmentation. It provides a clear understanding of data structure without requiring predefined cluster numbers.
